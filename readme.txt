Black Hangar — 0.3.1
===================
An editable WordPress block theme. Required content registration: CPT UI bh_portfolio.
Recommended SEO editor: Yoast SEO. No Elementor or ACF dependency.

Includes the reviewed Homepage and Film Studio layouts. This theme does not import
page content or register the portfolio content type. See README.md in the repository.

Fonts: Poppins, Barlow Condensed and Inter from the official google/fonts repository,
distributed under SIL Open Font License 1.1. Notices in assets/fonts/.
Theme code: GPL-2.0-or-later. WordPress core block libraries are not bundled.
Hero still: publicly archived Black Hangar Studios image; owner-authorized site use.
No captured proprietary font files or credentials are included.

Portfolio records remain in WordPress when switching themes. CPT UI must remain
active to register the post type. The editing metabox and display blocks are
theme-specific and will need replacement if switching to another theme.

Site Editor changes are database overrides. Back them up/export before updates.
Test updates on staging. No guarantee of complete security; keep dependencies updated.
